## B. 30 個互動 UI（24–53）

# SnowRealm Drama Studio V1｜互動 UI 設計與開發規格

> 規格版次：Draft 1.0；共 30 個互動設計編號（24–53）。此文件是可交付工程的功能規格，不代表 30 張獨立高解析 UI 圖已完成。

## 一、既定技術與權限

- 前端：Next.js App Router、TypeScript、Tailwind CSS。部署：Vercel。
- 資料庫：Neon PostgreSQL（Drizzle ORM）；物件儲存：Cloudflare R2 私有 Bucket。
- 僅兩個真人帳號：暖寶（CEO）與林鍶恩／Luffysky（技術總監），兩人均為 Owner；不提供公開註冊或邀請。
- AI 供應商使用可插拔後端適配器；API 金鑰不暴露於前端；AI 結果一律人工確認才寫入正式資料。
- 不製作內建影片剪輯器；剪輯在外部工具進行。

## 二、互動 UI 共通規範

每一張設計編號對應一個主要 Dialog／Drawer／Fullscreen Overlay；每個 Tab 都需要獨立 UI 狀態設計與驗收，不能只畫標籤。

每個互動至少包含：初始／空狀態、輸入驗證、載入中、成功、失敗、權限不足、取消未儲存、鍵盤操作、手機窄版。AI 互動另含額度不足、生成失敗、重試、成本預估、候選比較及人工套用。

路由不為每個彈窗另設頁面，採用既有主頁面中的受控元件；必要時可用 query 參數支援深連結。
