## 2. 普查裡還沒修完的（11-09 查出來的）

### 2-1　`drizzle/meta/_journal.json` 只記到 0015　**今天繞過去了，但沒修**

0016–0037 這二十二支不在 journal 裡，所以 `drizzle-kit migrate` 看不到它們。

**今天做了 `scripts/apply-migration.ts` 取代它**，而且正式庫的
`public.applied_migrations` 已經建好、38 支全部認列完成。所以這條**不再是定時炸
彈**，但 `npm run db:migrate` 仍然是一支會說謊的指令——它看起來能用，實際會少建
二十幾支的東西。

**最小的修法**：讓 `db:migrate` 直接拒跑並指向 `db:apply`。
