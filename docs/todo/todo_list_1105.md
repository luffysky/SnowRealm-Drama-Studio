### Z141 的實情

EP001 跑過了：74 句判出 73 句，而且**順帶抓出九個不在角色表裡的人**。
EP002 沒跑，所以它整集只有旁白一個聲音——你之前問的「現在只有一集有聲音?」
就是這個原因，不是壞掉。

### Z142 為什麼要重產

現有那兩個檔案是 Z140 之前做的，同時中了四個：

- 唸「星號星號星號」（全書 69 處場景分隔線）
- 「還錢」唸成 ㄏㄞˊ 錢、「頓了頓」第二個頓唸成 ㄉㄨˊ
- 沒有情緒風格（EP002 現在算得出 29 處）
- 沒有用釘住的音色（`voiceId` 當時根本沒被查出來）

### Z143 要選的那條路

峰值是**上傳時在瀏覽器算的**，而 TTS 檔案由 worker 直接寫進 R2，沒走過那條路。
補的方法有三條，差別很實在：

1. **加一支代理位元組的路由** —— 波形 JSON 那支已經為了同樣的 CORS 理由這樣
   做了，所以有前例。代價是 5 MB 的檔案要穿過一次函式。
2. **幫 R2 bucket 設 CORS** —— 最乾淨，但要動儲存桶設定，而且現有註解當初
   刻意選了代理而不是這個。
3. **在 worker 裡用 WASM 解碼器算** —— 不必下載兩次，但**要加一個新依賴**，
   而你說過新套件要先掃過。

我的建議是 1：有前例、不動儲存桶、不加依賴。
