## A. 外部服務帳號

你說過自己開，這裡只列**開完後要給我什麼**。詳細步驟見 [ENVIRONMENT.md](ENVIRONMENT.md)。

### A1. Neon PostgreSQL

- [ ] 建立專案，region 建議 `Asia Pacific (Singapore)` 或 `Tokyo`
- [ ] 取得 **pooled** 連線字串（host 含 `-pooler`）
- [ ] 取得 **direct** 連線字串（host 不含 `-pooler`）
- [ ] 建一個 `dev` branch，另外取得它的兩條字串（本機開發用，避免寫到正式資料）

> 兩條都要。應用程式走 pooled，migration 必須走 direct —— PgBouncer 的 transaction 模式不支援 migration 需要的 session 級鎖。

### A2. Cloudflare R2

- [ ] 建立 bucket，建議名稱 `snowrealm-drama-studio`，location 選 `Asia-Pacific (APAC)`
- [ ] **確認維持私有** —— 不要開 `r2.dev` Public Development URL，不要綁自訂網域
- [ ] 建立 API Token：權限選 **Object Read & Write**（不是 Admin），範圍限定這一個 bucket
- [ ] 記下 Account ID（32 碼十六進位）、Access Key ID、Secret Access Key

> ⚠️ Secret Access Key **只會顯示一次**，關掉視窗就看不到了，請立刻存進密碼管理器。

- [ ] 設定 CORS（**不設的話瀏覽器上傳會直接失敗**）：

```json
[
  {
    "AllowedOrigins": ["http://localhost:3400", "https://你的專案.vercel.app"],
    "AllowedMethods": ["GET", "PUT", "HEAD"],
    "AllowedHeaders": ["content-type", "content-length"],
    "ExposeHeaders": ["etag"],
    "MaxAgeSeconds": 3600
  }
]
```

`ExposeHeaders` 一定要有 `etag`，否則大檔分段上傳合併時會失敗。

### A3.（選用）Anthropic API

- [ ] 若要啟用 AI 功能，到 <https://console.anthropic.com> 取得 API key

> 沒有也能跑。AI 功能會顯示明確的「尚未啟用」狀態，其餘所有功能不受影響。

## C. 介面裝飾圖（4 張）

**GPT 可以生。** 生好放進 `public/` 資料夾，我會接上。

**沒有也不影響執行** —— 目前用漸層佔位（`.art-placeholder`），看起來是刻意的表面而不是破圖。

### 共通風格

> 深紫藍夜色、霓虹輝光、中國古風、電影感質地。
> **不要有文字、不要有人臉特寫、不要有浮水印。**
> 參考 `UI Design/01_dashboard.png` 的色調。

### C1. `public/logo-mark.png`

- **尺寸**：512 × 512，透明背景 PNG
- **內容**：雪花紋章，紫色到青色漸層，帶微光
- **要求**：單一圖形、**不含文字**、置中、四周留 10% 邊距
- **用在**：側欄品牌區（顯示 32px）、favicon

### C2. `public/rail-foot.png`

- **尺寸**：512 × 400，PNG
- **內容**：古風夜景，燈籠微光，遠山或屋簷剪影
- **要求**：**整體偏暗**（上面要疊文字）、**上緣與左右淡出到透明**、底部可實
- **用在**：側欄最下方的裝飾

### C3. `public/hero-banner.png`

- **尺寸**：1920 × 400，PNG 或 JPG
- **內容**：古風夜景橫幅 —— 燈火、櫻花、月色、屋宇
- **要求**：**左側 40% 必須夠暗**（要疊「晚安，暖寶」這類文字）、右側可以亮
- **用在**：儀表板頂部問候橫幅

### C4. `public/login-bg.png`

- **尺寸**：1920 × 1080，PNG 或 JPG
- **內容**：同風格，但**更暗、更散焦**
- **要求**：**中央必須很暗**（登入卡片會蓋在正中間）
- **用在**：登入頁背景
