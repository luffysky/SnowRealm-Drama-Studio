# 匯入範本

**這個資料夾是程式產生的。** 要改內容請改 `src/lib/import/targets.ts`，
再跑 `npx tsx scripts/write-import-templates.ts --write`。

## 怎麼用

1. 把 `檔名規格.md`、要用的那一份 `說明/<區塊>.md` 與 `範本/<區塊>.csv`
   一起貼給模型。
2. 請它照同樣的欄位產資料，並照檔名規格命名。
3. 回到網站把檔案丟進匯入——可以一次丟很多個，檔名會決定每一個是給哪一區的。

## 有哪些區塊

- **分鏡鏡頭**（`shots`）：一列一個鏡頭。景別與運鏡認不得的值會自動新增成選項。
- **角色設定**（`characters`）：一列一個角色。姓名必填，同名的會跳過不覆蓋。
- **世界觀條目**（`world`）：一列一個條目。名稱必填。
- **集數大綱**（`episodes`）：一列一集。集號必填；已經存在的集會更新大綱，不會重複建立。
- **小說章節**（`chapters`）：一列一章，接在這一集既有章節後面。
- **劇本場次**（`scenes`）：一列一場，接在這一集既有場次後面。
- **任務**（`tasks`）：一列一個任務。
- **支出紀錄**（`expenses`）：一列一筆。金額只填數字，幣別分開一欄——金額不可虛構。

## 要緊的幾件事

- 欄位名稱不用一模一樣，繁簡與英文鍵名都認得。
- 編碼建議 UTF-8；Big5／GBK 也讀得進來，細節在 `檔名規格.md`。
- 匯入前一定會先讓你看對應結果與問題列表，確認了才寫進去。
- **金額不要自己編。**
